TelePort TV Guide

🔗 Connection Guide

1. Install and launch the TelePort TV app on your Android TV device.

2. Find the TV's IP address on the TV screen (e.g., 192.168.1.15) and make sure both devices are on the same local Wi-Fi.

3. Enter the TV IP in the connection box above and click Save.

⚡ Core Actions

  • Tab Cast: Live mirror the active Chrome tab to the TV.
  • Cast Video: Detect, extract and stream web videos directly in full screen.
  • Beam URL: Open the current website in the TV's native browser.
  • Context Menu: Right-click anywhere on a webpage to quickly beam or cast it.

🖱️ Interactive Remote

Use the Trackpad tab to move the cursor (drag), click (tap), and scroll pages (two-finger scroll). Use the Buttons tab for direction pad controls, Back, and Play/Pause.
